# 战斗系统设计文档

> 本文档定义回合制战斗系统的完整设计，包括数值体系、状态机、UI交互和结算流程。

---

## 一、数值设计

### 1.1 战斗属性

| 属性 | 说明 | 范围 |
|------|------|------|
| 生命 (HP) | 生命值，≤0时死亡 | 0 ~ max_hp |
| 内力 (Qi) | 技能消耗资源 | 0 ~ max_qi |
| 攻击力 (ATK) | 造成伤害基础值 | 1 ~ 999 |
| 防御力 (DEF) | 减伤计算 | 0 ~ 999 |
| 速度 (SPD) | 决定行动顺序 | 1 ~ 999 |
| 暴击率 (CRIT) | 暴击概率 | 0% ~ 100% |
| 暴击伤害 (CRIT_DMG) | 暴击时伤害倍率 | 150% ~ 300% |

### 1.2 伤害公式

```
最终伤害 = max(1, 攻击方.ATK - 受击方.DEF)
如果暴击: 伤害 *= 攻击方.CRIT_DMG
```

### 1.3 境界加成

| 境界 | 攻击加成 | 防御加成 | 生命加成 |
|------|----------|----------|----------|
| 后天 | +0% | +0% | +0% |
| 先天气 | +10% | +5% | +20% |
| 筑基 | +20% | +10% | +50% |
| 金丹 | +30% | +15% | +100% |
| 元婴 | +40% | +20% | +150% |
| 化神+ | +50% | +25% | +200% |

## 二、战斗状态机

```
                    ┌─────────────┐
                    │    IDLE     │ (等待开始)
                    └──────┬──────┘
                           │ start_battle()
                           ▼
              ┌────────────────────────┐
              │     PLAYER_TURN       │ (玩家行动)
              └───────────┬────────────┘
        ┌────────────┬────┴────┬────────────┐
        │            │         │            │
   choose_attack choose_skill choose_item  try_escape
        │            │         │            │
        ▼            ▼         ▼            ▼
   ┌─────────────────────────────────────────┐
   │           ANIMATING (播放动画)           │
   └────────────────────┬────────────────────┘
                        │ animation_finished
                        ▼
            ┌────────────────────────┐
            │     ENEMY_TURN       │ (敌人AI行动)
            └───────────┬──────────┘
                        │
                   enemy_action
                        │
                        ▼
            ┌────────────────────────┐
            │  check_battle_end?    │
            └───────────┬──────────┘
                 ┌──────┴──────┐
          yes     │             │ no
           ┌─────▼─────┐       │
           │   ENDED   │◄──────┘
           │  (结算)    │
           └───────────┘
```

### 状态说明

| 状态 | 说明 | 可用操作 |
|------|------|----------|
| IDLE | 战斗未开始 | 开始战斗 |
| PLAYER_TURN | 玩家回合 | 攻击/技能/物品/逃跑 |
| ENEMY_TURN | 敌人回合 | 自动执行AI |
| ANIMATING | 动画播放中 | 等待动画结束 |
| ENDED | 战斗结束 | 查看结算 |

## 四、战斗流程

### 4.1 回合流程

```
1. 回合开始
   └─ 显示"你的回合"提示

2. 玩家选择行动
   ├─ 攻击: 直接造成普攻伤害
   ├─ 技能: 消耗内力，造成技能指定伤害
   ├─ 物品: 使用背包中的丹药/暗器
   └─ 逃跑: 50%概率成功

3. 播放行动动画/效果
   └─ 等待动画完成

4. 判定敌人是否死亡
   └─ 是 → 进入结算

5. 敌人回合
   ├─ AI选择目标/技能
   └─ 执行攻击

6. 播放敌人行动动画

7. 判定玩家是否死亡
   └─ 是 → 进入结算

8. 返回步骤1
```

### 4.2 胜负判定

| 条件 | 结果 |
|------|------|
| 所有敌人 HP ≤ 0 | 胜利 |
| 玩家 HP ≤ 0 | 失败 |
| 逃跑成功 | 逃跑（算作失败） |

## 六、技能配置

技能通过 SkillData 定义：

```gdscript
class_name SkillData
extends Resource

var skill_id: String
var name: String
var description: String
var damage: int           # 技能伤害
var qi_cost: int          # 内力消耗
var cooldown: int         # 冷却回合
var target_type: int      # 0=敌方单体, 1=敌方全体, 2=我方单体
```

## 八、数据流

```
GameState
  └─ current_battle: BattleManager (当前战斗实例)

BattleManager
  ├─ player: CombatUnit (玩家战斗单位)
  ├─ enemies: Array[CombatUnit] (敌人列表)
  ├─ state: BattleState (状态机)
  ├─ battle_log: Array[String] (战斗日志)
  │
  ├─ start_battle(player, enemies)
  ├─ execute_player_attack(target_index)
  ├─ execute_player_skill(skill_index, target_index)
  ├─ execute_player_item(item_index, target_index)
  ├─ try_escape() -> bool
  └─ end_battle(victory)

BattleUI (场景)
  ├─ 显示双方状态
  ├─ 显示操作按钮
  ├─ 播放动画效果
  └─ 显示战斗日志

BattleResult (场景)
  ├─ 显示胜负
  ├─ 显示奖励
  └─ 返回/重战按钮
```
