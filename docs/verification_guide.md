# 武侠沙盒 - 功能验证指南

## 启动流程

```
Godot 4.6 打开项目
        ↓
   主菜单 test_menu.tscn
   (WASD/方向键移动选择, E/回车确认)
        ↓
   选择测试场景进入
```

---

## 测试场景清单

| 场景 | 文件 | 验证内容 | 主要按钮 |
|------|------|----------|----------|
| 世界生成 | verify_world_gen.tscn | 区域/路径/名称/随机种子 | 重新生成、执行所有测试 |
| 时间系统 | verify_time.tscn | 日计数/季节切换/加速暂停 | +1天/+10天/暂停/执行测试 |
| 战斗系统 | verify_battle.tscn | 伤害计算/技能/逃跑 | 开始战斗/执行伤害测试 |
| 养成系统 | verify_cultivation.tscn | 经验/等级/属性/境界 | +经验/分配点/执行测试 |
| NPC AI | verify_npc.tscn | 4种AI类型/目标选择 | 生成NPC/模拟1天/执行测试 |
| 综合沙盒 | main.tscn | 所有模块整合 | WASD移动/按钮控制 |

---

## 操作指南

### 主菜单
- `↑↓` 切换选项
- `E` 或 `回车` 进入
- `ESC` 返回（已在子场景时）

### 各验证场景通用操作
| 按键 | 功能 |
|------|------|
| `ESC` | 返回主菜单 |
| `空格` | 执行该场景的主测试 |
| `回车` | 启动战斗/生成NPC |

---

## 场景详细说明

### 1. 世界生成测试 `verify_world_gen.tscn`

**验证目标：**
- 程序化生成5-10个区域
- 区域有唯一武侠风格名称
- 路径连接有效（MST + 额外路径）
- 相同seed生成相同世界

**操作步骤：**
1. 进入场景后自动生成世界
2. 查看「世界信息」面板确认区域数量
3. 点击「执行所有测试」自动验证各项指标
4. 点击「重新生成(seed=随机)」测试随机性

**预期输出示例：**

### 3. 战斗系统测试 `verify_battle.tscn`

**验证目标：**
- 伤害计算正确（攻击 - 防御，最低为1）
- 技能效果正确（伤害/气力消耗/冷却）
- 逃跑成功率约50%
- 战斗结束正确结算经验

**操作步骤：**
1. 点击「开始战斗(2山贼)」进入战斗
2. 观察战斗日志中的伤害数值
3. 点击「执行伤害测试」自动验证数值
4. 点击「执行技能测试」验证技能系统
5. 点击「执行逃跑测试」验证逃跑机制

**伤害计算公式：**
```
实际伤害 = max(1, 攻击方攻击力 - 防御方防御力)
```

**预期输出示例：**
```

--- 玩家回合 ---

--- 敌人回合 ---
山贼Lv2: 山贼Lv2 attacks 测试玩家, deals 5 damage

=== 伤害测试 ===
[PASS] 伤害计算正确: attack=15 def=3 → 实际伤害=12 (期望=12)
[PASS] 最低伤害=1 正确
[PASS] 生命≤0时is_alive=false 正确

=== 测试结果 ===

```

## 问题快速定位

| 现象 | 可能问题 | 检查位置 |
|------|----------|----------|
| 无法进入某测试场景 | .tscn文件缺失或路径错误 | project.godot 或 scene文件 |
| NPC显示但不动 | `_on_sandbox_tick` 未被调用 | main.gd / NPCManager |
| 战斗无限循环 | `battle_ended` 信号未触发 | battle_manager.gd |
| 经验获取不增加 | `SignalBus.exp_gained` 未连接 | cultivation_system.gd |
| 区域数量异常 | `world_generator.gd` 随机逻辑 | region count 5-10范围 |
| 季节不切换 | `advance_day()` 季节计算 | time_manager.gd |
| NPC类型显示? | ai_type超出0-5范围 | NPCManager 或 npc_agent.gd |
| 伤害为负 | `max(1, ...)` 未执行 | combat_unit.gd |
