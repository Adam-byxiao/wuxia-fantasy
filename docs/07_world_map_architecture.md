# 世界地图重构草案

## 目标

项目采用“双层一体”地图结构：

1. 大地图是可直接游玩的 `tile/world map`
2. 城镇、门派、据点、遗迹入口等地点可从大地图进入子地图

这样既保留江湖旅行感，也保留据点内的细交互空间。

## 分层模型

### 1. WorldMap

承载大地图层：

- 地形 tile
- 路径网络
- 世界区域
- 世界地点入口
- 世界时间推进
- 野外事件与移动

### 2. Region

`Region` 表示世界级分区，不等同于具体可进入场景。

职责：

- 难度分层
- 势力/生态分区
- NPC 活动范围
- 地图上的区域标签

不再承担：

- 子地图本体
- 具体场景切换目标

### 3. Location

`Location` 表示大地图上的具体地点入口。

示例：

- 村庄
- 城镇
- 门派
- 山庄
- 遗迹入口
- 秘境入口

职责：

- 归属某个 `Region`
- 在大地图上有明确坐标
- 可选绑定一个子地图场景

### 4. SubMap

`SubMap` 是进入地点后的局部交互地图或场景。

示例：

- `town_scene.tscn`
- `sect_scene.tscn`
- 后续的客栈、山门、遗迹内部等

职责：

- 对话
- 商店
- 室内/据点互动
- 任务交付
- 建筑设施

## 当前代码映射

本轮重构新增或调整了以下结构：

- `scripts/world/location_data.gd`
  - 新的地点数据结构
- `scripts/world/world_data.gd`
  - 增加 `locations`
  - 增加地点查询接口
- `scripts/world/region_data.gd`
  - 增加 `location_ids`
- `scripts/core/game_state.gd`
  - 增加当前地点与当前子地图状态
- `scripts/core/save_system.gd`
  - 增加地点相关存档字段
- `scripts/world/world_generator.gd`
  - 生成示例区域、路径和地点
- `scripts/world/world_renderer.gd`
  - 渲染路径与地点

## 设计原则

### 原则一：世界层和交互层分离

大地图负责“到哪里去”，子地图负责“到了之后做什么”。

### 原则二：远距离移动走区域/路径网络

NPC 和世界模拟不必做全图逐格寻路。

推荐：

- 世界层移动：按区域图与路径图
- 地点内部移动：按局部地图逻辑

### 原则三：地点是进入子地图的入口，不是区域本身

以后如果一个区域里有多个可进入地点，也不需要再改区域模型。

例如：

- 一个山地区域里可以同时有
  - 门派山门
  - 山洞入口
  - 驿站

## 后续迁移建议

### 第一阶段

- 让主场景以大地图为主入口
- 点击/接近 `Location` 后可进入对应子地图
- 将 `town_scene.tscn`、`sect_scene.tscn` 挂到地点入口

### 第二阶段

- 用正式的大地图生成逻辑替换当前示例结构
- 将路径、道路、水路、山道纳入统一数据
- 为地点增加类型化交互配置

### 第三阶段

- NPC 远行使用 `Location` 与 `Region` 混合图
- 世界事件直接落在大地图或地点入口
- 子地图回到大地图时保留入口位置
